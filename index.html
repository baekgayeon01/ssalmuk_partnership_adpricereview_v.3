적정 협상 범위 : 월 100~150만 원 (목표가 125만 원 이내)

  • ① 매체 가치 : 유사 매체 단가 비교 기준 → 월 100~150만 원
  • ② 거래 기여도 : 현행 배너 성과 기준 → 광고비 회수 근거 부족, 150만 원 초과 근거 없음
  • ③ 상호 제휴 가치 : 당사 시세 데이터 제공 및 개발 리소스 투입 → 단가 인하 근거

※ 월 100~150만 원은 유사 매체 단가와 트래픽으로 산정한 협상 범위이며, 실제 거래 성과로 검증된 가격은 아님

③ 상호 제휴 가치 : 당사 시세 데이터 제공

  • 이번 제휴는 배너 광고 구매가 아닌, 당사 시세·거래순위 데이터를 쌀먹 시세 게시판 콘텐츠로 제공하는 상호 제휴 구조
  • 쌀먹은 시세 게시판 신설로 콘텐츠 경쟁력 강화, 이용자 유입·재방문 증가 효과 기대 가능
  • 당사는 데이터 연동 개발(F/E·B/E·DBA) 및 유지보수 리소스 투입
  • → 일반 배너 광고 대비 단가 인하 또는 초기 무상 제휴 요청의 근거로 활용 (별도 금액 환산은 하지 않음)

02진행 방안

A안 · 유료 광고 전환

  • 협상 단계 : 최초 제시가 100만 원 → 목표가 125만 원 이내 → 상한 150만 원
  • 시세 제공은 양해각서 조건 유지, 광고비는 별도 계약
  • 오픈 후 월간 리포트(지면별·게임별 성과)로 단가 재검토

B안 · 무상 진행 후 재협의

  • 양해각서 조건(배너 바터 + 시세 제공, 무상)으로 시세 게시판 오픈
  • 오픈 후 3개월 실제 거래 전환 성과를 확인한 뒤 광고비 재협의
  • 재협의 시 적정 협상 범위(월 100~150만 원) 적용

※ 공통 : 결정 후 쌀먹 회신(광고비·계약 기간, 기간별 이력 1개월/6개월 변경 안내) → 연동 정보·명세서 전달 → 테스트 → 지면 구축·검수 → 오픈

03컨펌 요청 사항

01진행 방안 : A안(유료 광고 전환) / B안(무상 진행 후 재협의) 중 선택
02협상 단가 : A안 진행 시 협상 단계(제시가 100만 원 / 목표가 125만 원 이내 / 상한 150만 원) 확인
03결렬 시 대응 : 쌀먹이 협상 범위를 수용하지 않을 경우 B안 전환 또는 시세 연동 보류 여부
